# Upload signing certificate

`upload_certificate.pem` here is the public half of Honest Chess's upload key.
It is written by `tools/make_upload_key.sh`, committed on purpose, and read by
`tools/verify_upload_cert.sh` (release.yml) and `play-api-check.yml` to prove
a bundle, or the keystore secret, carries the key Play enrolled.

The private key and its password never enter this repository;
`test/guards/signing_guard_test.dart` asserts git ignores every file shape
they could arrive in, and `test/guards/signing_readme_test.dart` holds the
fingerprint below to the committed certificate.

| | |
|---|---|
| Alias | `upload` |
| Owner (dname) | `O=Honest Arcade, CN=Honest Chess` |
| Key | RSA 2048, SHA256withRSA, PKCS12, 10,000 days |
| Keystore | `~/HonestArcadeApps/secrets/honestchess-upload.keystore` (outside the repo) |
| SHA-256 | `41:84:0F:86:DC:F1:28:AF:58:91:73:9B:05:46:61:F7:49:82:29:0D:02:66:D0:EF:74:F8:43:80:46:77:AB:4C` |

| Created | SHA-256 fingerprint | Notes |
|---|---|---|
| 2026-09-27 | as above | generated by `tools/make_upload_key.sh` (#15) |

## Verify

```
keytool -printcert -file android/signing/upload_certificate.pem
```

prints the SHA-256 above. A release bundle's signer is checked against this
file by `tools/verify_upload_cert.sh` before anything is uploaded to Play.
